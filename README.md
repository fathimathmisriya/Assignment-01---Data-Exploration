# Excel Assignment 1 – Data Exploration

## Overview

This repository contains my Excel Assignment 1 on **Data Exploration**. 
The assignment focuses on analysing a product dataset using basic Excel functions and formulas.

## Tasks Completed

- Calculated the total price of all products using **SUM**
- Counted the total number of products using **COUNTA**
- Calculated the average product price using **AVERAGE**
- Identified the minimum and maximum prices using **MIN** and **MAX**
- Categorised products into **High Price** and **Standard Price** using **IF**
- Calculated the total price of Electronics products using **SUMIF**
- Counted products priced below ₹100 using **COUNTIF**
- Extracted the Day, Country Code, and Month from Product IDs using **LEFT, RIGHT, and MID**
